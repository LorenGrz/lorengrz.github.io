# Repository Context

## Purpose

- Personal portfolio project for presenting full-stack projects and developer experience.
- Includes a private admin flow for adding portfolio projects without source-code edits.

## Stack

- Next.js 16.2.9 with App Router.
- React 19.2.4 and React DOM 19.2.4.
- TypeScript 5.
- Tailwind CSS 4 through `@tailwindcss/postcss`.
- ESLint 9 with `eslint-config-next`.
- PostgreSQL access through `pg`.
- Runtime validation with `zod`.
- Package manager: pnpm 11.5.0.

## Project Structure

- `src/app/`: App Router entrypoint, layout, global styles, and home page.
- `src/app/api/projects/`: REST route handlers for listing and creating projects.
- `src/components/`: UI components, including the private project form.
- `src/lib/projects/`: Project domain model, validation, seed data, and PostgreSQL repository.
- `database/schema.sql`: relational schema for portfolio projects and project images.
- `aws/template.yaml`: SAM starting point for AWS serverless deployment with a Next.js adapter output.
- `public/`: static SVG assets generated by `create-next-app`.
- `next.config.ts`: Next.js configuration.
- `postcss.config.mjs`: Tailwind/PostCSS configuration.
- `eslint.config.mjs`: ESLint flat config.
- `pnpm-workspace.yaml`: pnpm build-script approvals for generated dependencies.

## Package Manager And Scripts

- Install dependencies: `pnpm install`.
- Start development server: `pnpm dev`.
- Production build: `pnpm build`.
- Start production server after build: `pnpm start`.
- Lint: `pnpm lint`.
- Typecheck: `pnpm typecheck`.

## Architecture Rules

- Use Next.js App Router patterns.
- Keep components as server components by default.
- Add `"use client"` only for interactive UI, browser APIs, or client-side hooks.
- Keep portfolio content data separate from presentational components once real content is added.
- Prefer TypeScript-safe data structures for projects, skills, links, and experience sections.
- Validate project creation requests at the API boundary with `zod`.
- Protect project writes with `ADMIN_TOKEN`; public clients may only read.
- Store project image metadata as relational records with URLs. Use S3/presigned uploads later for binary uploads.

## Testing And Verification

- Current generated project has lint and build scripts.
- Run `pnpm lint` after code changes.
- Run `pnpm typecheck` after type or API changes.
- Run `pnpm build` before considering UI or routing changes complete.
- Add tests when behavior becomes non-trivial or shared logic is introduced.
